### `/decir`

Enviar un mensaje a un canal de texto o al canal actual

**Permisos:** <Badge text="100" variant="note" size="small" />

<Tabs>
  <TabItem label="texto" icon="puzzle">
    Enviar un mensaje de texto a un canal

    **Opciones:**
    - **`texto`** <Badge text="TEXTO" variant="default" size="small" /> <Badge text="Requerido" variant="danger" size="small" />: El texto que se enviará
    - **`canal`** <Badge text="CANAL" variant="default" size="small" /> <Badge text="Opcional" variant="success" size="small" />: El canal donde se enviará el mensaje

    **Ejemplo de uso:**
    ```bash
    # Como comando de barra (slash command):
    /decir texto texto:texto_ejemplo

    # Con el prefijo configurado:
    -decir texto texto_ejemplo
    ```
  </TabItem>
  <TabItem label="embed" icon="puzzle">
    Enviar un mensaje en forma de embed

    **Opciones:**
    - **`título`** <Badge text="TEXTO" variant="default" size="small" /> <Badge text="Requerido" variant="danger" size="small" />: El título del embed
    - **`descripción`** <Badge text="TEXTO" variant="default" size="small" /> <Badge text="Requerido" variant="danger" size="small" />: La descripción del embed
    - **`color`** <Badge text="TEXTO" variant="default" size="small" /> <Badge text="Opcional" variant="success" size="small" />: El color del embed (Ej: #5865F2)
    - **`imagen`** <Badge text="TEXTO" variant="default" size="small" /> <Badge text="Opcional" variant="success" size="small" />: Enlace de la imagen del embed
    - **`pie`** <Badge text="TEXTO" variant="default" size="small" /> <Badge text="Opcional" variant="success" size="small" />: El pie del embed
    - **`canal`** <Badge text="CANAL" variant="default" size="small" /> <Badge text="Opcional" variant="success" size="small" />: El canal donde se enviará el mensaje

    **Ejemplo de uso:**
    ```bash
    # Como comando de barra (slash command):
    /decir embed título:texto_ejemplo descripción:texto_ejemplo

    # Con el prefijo configurado:
    -decir embed texto_ejemplo texto_ejemplo
    ```
  </TabItem>
  <TabItem label="editar" icon="puzzle">
    Editar un mensaje enviado por el bot

    **Opciones:**
    - **`id`** <Badge text="TEXTO" variant="default" size="small" /> <Badge text="Requerido" variant="danger" size="small" />: La id del mensaje a editar
    - **`texto`** <Badge text="TEXTO" variant="default" size="small" /> <Badge text="Requerido" variant="danger" size="small" />: El texto con el que se editará el mensaje

    **Ejemplo de uso:**
    ```bash
    # Como comando de barra (slash command):
    /decir editar id:42 texto:texto_ejemplo

    # Con el prefijo configurado:
    -decir editar 42 texto_ejemplo
    ```
  </TabItem>
  <TabItem label="temp" icon="puzzle">
    Mandar un mensaje temporal a un canal

    **Opciones:**
    - **`texto`** <Badge text="TEXTO" variant="default" size="small" /> <Badge text="Requerido" variant="danger" size="small" />: El texto que se enviará
    - **`tiempo`** <Badge text="TEXTO" variant="default" size="small" /> <Badge text="Requerido" variant="danger" size="small" />: El tiempo que durará el mensaje (Ej: 1s, 10m)
      <br/>*Nota: Las duraciones se expresan con un número y su unidad. Por ejemplo: `10m` son 10 minutos, `2d` son dos días y `1h15m30s` es una hora, 15 minutos y 30 segundos.*
    - **`canal`** <Badge text="CANAL" variant="default" size="small" /> <Badge text="Opcional" variant="success" size="small" />: El canal donde se enviará el mensaje

    **Ejemplo de uso:**
    ```bash
    # Como comando de barra (slash command):
    /decir temp texto:texto_ejemplo tiempo:1h30m

    # Con el prefijo configurado:
    -decir temp texto_ejemplo 1h30m
    ```
  </TabItem>
</Tabs>
