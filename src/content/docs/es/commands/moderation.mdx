Esta sección detalla todos los comandos disponibles en esta categoría.

<Aside type="caution">
  Ten en cuenta que los comandos pueden ser potentes. Asegúrate de configurar correctamente los permisos en tu servidor para evitar que usuarios no autorizados puedan usarlos.
</Aside>

## Lista de comandos

### `/avisar`

Dar un aviso razonado a un usuario.

**Alias:** `advertir`, `warn`, `w`, `a` | **Permisos:** <Badge text="100" variant="note" size="small" />

<Tabs>
  <TabItem label="Opciones" icon="setting">
    - **`usuario`** <Badge text="USUARIO" variant="default" size="small" /> <Badge text="Requerido" variant="danger" size="small" />: El usuario al que se le dará el aviso.
    - **`razón`** <Badge text="TEXTO" variant="default" size="small" /> <Badge text="Opcional" variant="success" size="small" />: La razón por la que se le da el aviso.
    - **`md`** <Badge text="BOOLEANO" variant="default" size="small" /> <Badge text="Opcional" variant="success" size="small" />: Si se le enviará el aviso por MD.
  </TabItem>
  <TabItem label="Ejemplo de uso" icon="rocket">
    ```bash
    # Como comando de barra (slash command):
    /avisar usuario:@Pepe

    # Con el prefijo configurado:
    -avisar 123456789012345678
    ```
  </TabItem>
</Tabs>
