Esta sección detalla todos los comandos disponibles en esta categoría.

<Aside type="caution">
  Ten en cuenta que los comandos pueden ser potentes. Asegúrate de configurar correctamente los permisos en tu servidor para evitar que usuarios no autorizados puedan usarlos.
</Aside>

## Lista de comandos

### `/avatar`

Mostrar el avatar de un usuario o el tuyo

**Alias:** `av`, `pfp`, `profilepic`, `profilepicture` | **Permisos:** <Badge text="50" variant="note" size="small" />

<Tabs>
  <TabItem label="Opciones" icon="setting">
    - **`usuario`** <Badge text="USUARIO" variant="default" size="small" /> <Badge text="Opcional" variant="success" size="small" />: El usuario del que se mostrará el avatar
  </TabItem>
  <TabItem label="Ejemplo de uso" icon="rocket">
    ```bash
    # Como comando de barra (slash command):
    /avatar

    # Con el prefijo configurado:
    -avatar
    ```
  </TabItem>
</Tabs>

### `/recordar`

Crea un recordatorio con una duración definida

**Permisos:** <Badge text="80" variant="note" size="small" />

<Tabs>
  <TabItem label="Opciones" icon="setting">
    - **`tiempo`** <Badge text="TEXTO" variant="default" size="small" /> <Badge text="Requerido" variant="danger" size="small" />: En cuanto tiempo quieres que te recuerde, ej: 1h, 10m
      <br/>*Nota: Las duraciones se expresan con un número y su unidad. Por ejemplo: `10m` son 10 minutos, `2d` son dos días y `1h15m30s` es una hora, 15 minutos y 30 segundos.*
    - **`mensaje`** <Badge text="TEXTO" variant="default" size="small" /> <Badge text="Requerido" variant="danger" size="small" />: Que quieres que te recuerde
  </TabItem>
  <TabItem label="Ejemplo de uso" icon="rocket">
    ```bash
    # Como comando de barra (slash command):
    /recordar tiempo:1h30m mensaje:texto_ejemplo

    # Con el prefijo configurado:
    -recordar 1h30m texto_ejemplo
    ```
  </TabItem>
</Tabs>
